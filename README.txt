CARA MENJALANKAN (XAMPP)
1. Jalankan Apache dan MySQL di XAMPP Control Panel.
2. Salin folder "perpustakaan" ke C:\xampp\htdocs\
3. Buka http://localhost/phpmyadmin -> tab Import -> pilih database.sql -> Go.
4. Buka http://localhost/perpustakaan/
5. Login: username = admin | password = admin123

Catatan: tampilan Bootstrap memakai CDN, jadi butuh koneksi internet.
Jika password MySQL root kamu tidak kosong, ubah di koneksi.php.
